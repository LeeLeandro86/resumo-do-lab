# resumo-do-lab
Este repositório contém o resumo do laboratório do Azure localizando serviços.

Aprendi nessa aula de projeto a localizar os serviços no Azure, por categoria, como por exemplo serviços de computação, armazenamento e redes de forma apenas visual de como localizar os serviços na plataforma. Uma coisa importante de ressaltar que teve na aula seria os serviços que estão como "prévios", que o ideal seria evitar de colocar em produção, pois não tem SLA, e como está em fase de testes, pode ser efetivado futuramente, ou retirado da plataforma.

Após a aula naveguei por algumas categorias, como Devops, onde tem as suas ferramentas, projetos e os service connections, para integração com outras plataformas e Banco de dados, onde pode selecionar um banco SQL do azure para armazenar os dados de uma aplicação.
